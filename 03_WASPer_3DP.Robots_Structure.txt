Scope
A separate, optional Grasshopper assembly (its own GH_AssemblyInfo and plugin GUID, builds
its own .gha) reserved for Robots-plugin-dependent integration components. It is kept
physically separate from the main plugin (chapter 01) so that installing WASPer_3DP does not
force a dependency on the third-party Robots plugin for users who don't need it. It is one of
four chapters in WASPer_3DP.sln (one solution, one structure map per project):
  01_WASPer_3DP_Structure.txt          - the main plugin (all Grasshopper components)
  02_WASPer_3DP.AI_Structure.txt       - AI/canvas-bridge support library
  03_WASPer_3DP.Robots_Structure.txt   - this file - optional Robots-plugin integration
  04_WASPer_3DP.XR_Structure.txt       - LiveLink protocol + Gamma/vvvv process viewer, future XR

Update this file whenever a component is added to this project, or when its dependency on the
Robots plugin / Robots.Rhino package changes.

Active component source
Components\5.1_Robot Gcode contains the eight active Ro components. They are compiled only by
WASPer_3DP.Robots.csproj because they use the Robots.Rhino API and require the Robots plugin at
runtime. Keeping the files physically in this project prevents Visual Studio from presenting
active sources as excluded files under the core WASPer_3DP project.

# Support

Where to go, depending on what you need:

- **Documentation**: start with the [README](./README.md), the WASPet's built-in
  `wsp_path` guide, and the `*_Structure.txt` maps beside each Visual Studio project.
- **Bugs & feature requests**: file an issue on the
  [Issues page](https://github.com/jdvargas12/WASPer_3DP/issues). Please include the
  WASPer_3DP version, Rhino/Grasshopper version, a minimal definition or reproducible
  sequence, the complete warning or error, and relevant machine/material context.
- **Security vulnerabilities**: do **not** open a public issue; follow
  [SECURITY.md](./SECURITY.md) instead.
- **Everything else**: reach out to
  [Juan Diego Vargas](https://www.linkedin.com/in/juan-diego-vargas-vel/).

Please search existing issues before opening a new one.
